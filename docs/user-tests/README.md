# User test record

Manual verification for behavioural changes is recorded here. Each document is named
`YYYY-MM-DD-<slug>.md` (the date the test was run, then a short hyphenated slug).

Start from [TEMPLATE.md](./TEMPLATE.md). Rules, the minimum bar, and when a document is
required are in [TESTING.md](../TESTING.md).

Never edit a past document after it is merged. If something changed, write a new one.
