Before starting the scan service

  1. Stop the job server and worker if they were started by hand (./spark.sh stop), so port 8800 is free. The scan service refuses to start while something else is on it.
  2. Turn off their start at boot: comment out the @reboot … spark.sh start line with crontab -e. Otherwise a reboot starts them again and they take port 8800 back. Don't use the DGX Start button in the lab GUI's Rig tab either.
  3. Check that ssh {{ station.capture_host }} hostname works without a password for the user whose SSH folder is set here.
  4. The capture station's config.toml must point at this station ([server] url = "http://THIS_STATION_IP:8800") with the scan token above. If you pasted its existing token, nothing changes there.

The data folder /srv/scanbot is created on first start. GPU and disk checks run when you deploy.
